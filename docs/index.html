URBAN CHAOS

1999 · WebAssembly · WebGL2

The classic Mucky Foot action game, running right in a browser tab. The OpenChaos engine compiled to WebAssembly: the full game with cutscenes, sound and saves, nothing to install.

How to run it OpenChaos engine

Features

The whole game

Every mission, with physics and logic identical to the original: same engine, just built for the browser.

EN and RU

A launcher to pick the version. The Russian translation is a layer on top: only the files that differ are uploaded.

Cutscenes

Bink videos are transcoded to MP4 and play over the game; skip with Esc or a tap.

Gamepads

Xbox, PlayStation and generic controllers through the browser Gamepad API.

Touch controls

Phones and tablets get a floating stick, look-by-drag and action buttons, fed to the game as a virtual gamepad.

Streaming

Game files are downloaded only when needed, so startup is fast.

Saves

Progress and settings live in IndexedDB and survive page reloads.

Any host

The output is plain static files: Apache, nginx, S3, any file host.

Game files are not distributed. The repository contains only the engine and the web wrapper. To play you need your own legal copy of Urban Chaos: CD, Steam or GOG.

Up and running in 4 steps

  1. Engine

    Download openchaos.js and openchaos.wasm from Releases into web/dist/, or build them yourself (Emscripten SDK + CMake):

    powershell -ExecutionPolicy Bypass -File web\build.ps1   # Windows
./web/build.sh                                           # Linux / macOS

  2. Game files

    You need an installed game folder (with clumps/, levels/, talk2/, text/…). For Steam it is steamapps/common/Urban Chaos. The Russian version additionally needs the translation folder with the same layout.

  3. Build the site

    Node.js 18+ and FFmpeg (for cutscenes):

    node web/tools/prepare.js --game "path/to/Urban Chaos" --rus "path/to/translation" --out site
    site/
├─ index.html          launcher
├─ game.html           game
├─ touch.js            touch controls
├─ openchaos.js/.wasm  engine
├─ manifest_en.json    manifest_ru.json
└─ data/
   ├─ en/              game files
   └─ ru/              translation files only

  4. Run

    Test locally, then upload the contents of site/ to your host:

    node web/tools/serve.js site 8080   →   http://localhost:8080/

    For nginx add types { application/wasm wasm; }; for Apache everything is already in .htaccess.

Under the hood

WebGL2

The OpenGL 4.1 renderer runs on WebGL2: shaders are translated to GLSL ES 3.00 and missing texture formats are emulated.

Asyncify

The blocking game loop yields each frame to the browser via requestAnimationFrame without rewriting the game logic.

Lazy file system

Opening a file in the game transparently becomes a fetch; file-name case is resolved through a manifest.

SDL3 + OpenAL

Input, window and audio come from the Emscripten ports on top of WebAudio.
